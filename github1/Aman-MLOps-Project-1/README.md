# Aman MLOps Project 1 — House Price Estimator

An end-to-end learning project that demonstrates a reproducible house-price regression workflow: data generation, preprocessing, model comparison, evaluation, model persistence, a prediction API, Docker, automated tests, and GitHub Actions.

> **Data note:** The default dataset is deterministic synthetic data generated by this project, so training and tests work offline. It is for demonstrating the engineering workflow, not for making real-world property valuations. You can later replace it with a licensed/local real-estate dataset.

## What is included

- **Training pipeline:** compares a median baseline, Linear Regression, and Random Forest.
- **Evaluation:** MAE, RMSE, and R²; writes metrics to `artifacts/metrics.json`.
- **Preprocessing:** a scikit-learn `Pipeline` with numeric imputation and scaling.
- **Prediction API:** FastAPI endpoint at `/predict` and interactive docs at `/docs`.
- **Tests:** unit tests for data, training, and API input validation.
- **MLOps:** Docker image and GitHub Actions CI workflow.

## Run locally (Windows PowerShell)

Python 3.11 is recommended.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m src.house_price.modeling
```

The training command creates `artifacts/house_price_model.joblib` and `artifacts/metrics.json`.

Start the API after training:

```powershell
uvicorn app.main:app --reload
```

Open `http://127.0.0.1:8000/docs` to try the API.

Example request body:

```json
{
  "median_income": 6.2,
  "house_age": 25,
  "rooms": 1800,
  "bedrooms": 300,
  "population": 900,
  "households": 320,
  "latitude": 34.1,
  "longitude": -118.2
}
```

The response is an estimate in **hundreds of thousands of USD** because the synthetic target is scaled that way. It is a demonstration only.

## Run with Docker

Build the image (training runs during image build):

```powershell
docker build -t aman-house-price-mlops .
docker run --rm -p 8000:8000 aman-house-price-mlops
```

Then visit `http://localhost:8000/docs`.

## Continuous integration

The workflow in `.github/workflows/ci.yml` installs dependencies and runs tests on pushes and pull requests to `main`.

## Push to your GitHub

1. Download and extract this project ZIP.
2. In GitHub, create a **public, empty** repository named `Aman-MLOps-Project-1` under your account. Do not initialize it with a README, license, or `.gitignore`.
3. Open PowerShell in the extracted `Aman-MLOps-Project-1` folder and run:

```powershell
git init
git add .
git commit -m "Build house price MLOps pipeline"
git branch -M main
git remote add origin https://github.com/villanious1/Aman-MLOps-Project-1.git
git push -u origin main
```

If Git asks you to sign in, complete the browser authentication prompt. Do not paste a password or access token into this chat.

If the remote repository already contains commits, check its contents first; do not force-push over existing work.

## Important limitations

- The generated dataset is synthetic and should not be used for financial or real-estate decisions.
- Metrics are produced when you run training; they are not hard-coded benchmark claims.
- The serialized model is generated locally and is intentionally excluded from Git. Train it after cloning or let the Docker build create it.
- This is an educational portfolio project, not a production valuation service.
